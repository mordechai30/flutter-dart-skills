# RenderView class

One view of a `Scene`: a 【3†camera】 plus where and how its image is drawn.

A scene can be rendered as a list of views (split-screen, picture-in- picture, and more). Each view binds a camera to a 【4†target】 (an offscreen 【5†RenderTexture】, or null for the screen), a 【6†viewport】 sub-rectangle of the target, a 【7†layerMask】 selecting which nodes it sees, an 【8†order】 controlling how overlapping views composite, and an optional 【9†antiAliasingMode】 override.
